Factory Inventory Management System

The architecture of a full-stack demo app: a Vue 3 single-page app talking to a FastAPI service that serves in-memory mock data loaded from JSON files. There is no database and no authentication.

System architecture

Three layers run on one machine. The browser loads the app from the Vite dev server on port 3000, then calls the API on port 8001 directly.

Data flow

What happens when someone changes a filter on the Dashboard.

  1. The user picks a filter in FilterBar.vue, for example Warehouse = "San Francisco". That writes to a ref in useFilters.js. The refs live at module level, so every view shares the same filter state.
  2. The view reacts. Dashboard.vue has a watch() on all four filter refs and reloads its data, calling getCurrentFilters(). That maps location to warehouse and period to month.
  3. api.js builds the request. It drops any filter set to 'all' and sends parallel GETs, such as /api/dashboard/summary?warehouse=San%20Francisco, plus /orders, /inventory and /backlog.
  4. FastAPI filters in memory. apply_filters() matches warehouse, category and status. filter_by_month() substring-matches order_date (2025-03) or expands a quarter (Q1-2025) into its three months.
  5. The response is computed and validated. List endpoints return Pydantic models. The summary endpoint computes totals such as inventory value, low-stock count and pending orders on every request.
  6. Vue renders. Raw responses go into refs, and computed() properties derive the KPIs, charts and tables. For example, the revenue goal is $800K for a single month or $9.6M across all months.

Known gaps

Places where the frontend and backend disagree, found while investigating.

Missing endpoints

The api.js file defines calls to /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders (GET, POST), but main.py doesn't implement them. App.vue requests the tasks list on every load and gets a 404.

Unrouted view and stale test docs

Backlog.vue exists but has no route. tests/README.md lists a test_orders.py file and 51 tests; the file doesn't exist and the suite has 40.
